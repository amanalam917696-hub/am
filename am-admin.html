Visitors
—Total Page Visits (public site load hone par count hota hai)

Ye counter countapi.mileshilliard.com naam ki free service se aata hai — ye sabhi visitors ka real count hai, sirf aapke device ka nahi. Lekin ye ek chhota free service hai, hamesha ke liye guarantee nahi hai. Lambe samay ke liye reliable tracking chahiye to website mein Google Analytics laga dein (free, Google ka apna tool) — bataiye to main uska code bhi jod dunga.

Ads Kaise Lagayein
  • Sabse pehle Google AdSense (ya koi aur ad network) par account banayein aur apni website submit karein — approval milne mein kuch din lagte hain.
  • Approval ke baad AdSense aapko ek chhota sa script code dega — wo public site ki <head> section mein daal dein. Isse "Auto Ads" chalu ho jaata hai, jo khud-ba-khud sahi jagah par ads dikhata hai.
  • Public site mein jo #interstitial overlay hai (jo tool kholte hi automatically dikhta hai) — usmein apna AdSense "Interstitial" ya "Anchor" ad unit ka code daal sakte hain, taaki har click par real ad chale.
  • Jitne bhi "Advertisement" wale dashed box hain website mein, wahan bhi AdSense ka display ad unit code daal dein.

Main AdSense account khud nahi bana sakta (ye Google ki approval process hai), lekin jaise hi aapke paas ad code ho, main use website mein sahi jagah fit kar sakta hoon.
